# fleet_manager
Enterprise Fleet Manager zur Verwaltung von Fahrzeugflotten mit Python. Das Projekt demonstriert OOP, Vererbung, Polymorphismus, Lambda-Funktionen, Custom Exceptions und flexible Fahrzeuganalysen.
